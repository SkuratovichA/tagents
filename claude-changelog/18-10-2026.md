[08:48] The notify helper's bundle id follows its icon: macOS keeps an app's notification icon from its first permission request, so the owner's app, which first asked before it had an icon, showed a generic icon in every notice and in System Settings. With an icon, `build.sh` now names the app `<base>.i<first 8 hex of the icon's sha256>`, the helper's `status` reports the id it runs under, and the System Settings link follows it. A changed icon is a new registration: macOS asks once more to allow notifications.
