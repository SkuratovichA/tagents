[10:31] Archive folders stay out of the prompt. Worktree `wt/notes-archive` on branch `feature/notes-archive`. `hooks/notes-context.sh` diffs with `':!prompt.md' ':!archive/*' ':!*/archive/*'`, so nothing under an `archive/` folder — at the top of the notes or inside a ticket's folder — is replayed, and a commit that only touches an archive banks the marker and injects nothing, like an outbox-only commit. A document moved into an archive would have come back as a deletion of its whole text once its new path was excluded (git pairs the rename with nothing), so the hook first lists the renames with both paths in play (`diff -M --name-status`, with `core.quotePath=false` so a non-ASCII name is not escaped), excludes each old path as `:(exclude,literal)<old>`, and puts one line in the stat instead: ` archived: doc.md => AA-7/archive/doc.md`. A document moved back out is an addition again. `tnotes` `changed_artifacts` uses the same three pathspecs for the @-mentions, plus `--diff-filter=d`: a path that is gone cannot be attached, which is also what a move into an archive looks like there.
