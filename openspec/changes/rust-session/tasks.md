The tasks serve `session open`, `session list`, `session last`, `session prompt` and `session abort` from the Rust binary and leave `session` with no verb or an unknown verb with node. The change ships in three pull requests, merged in this order, each with the node fallback intact because a verb is served only when its `impl` flag says `rust` and each flag is flipped last among the code of its pull request. (1) Groups 1 to 7: the decoder fix in node, the pins, the shared grammar with `plugin.rs` moved onto it, the exact strings, the state `pid`, the `session` group with `open`, `list` and `last`, and the parity suite with its stub. (2) Groups 8 to 13: `prompt`, its supervisor, the events, the keep-awake hold and the scenarios of a turn. (3) Groups 14 to 16: `abort`, the documents and the archive. Groups 2 to 14 change inputs of the binary (`is_input` in `.github/scripts/core-release.sh` covers `Cargo.toml`, `Cargo.lock`, `crates/*/src/*` and `spec/cli/*`), so each pull request raises the workspace version one step above its merge base (`sh .github/scripts/core-release.sh gate origin/main` prints what to change), and a pull request that rebases onto a version another one raised raises it again. Every gate runs in the worktree of the pull request, shell suites as `env -u TMUX -u TMUX_PANE TMUX_TMPDIR="$(mktemp -d)" bash tests/<suite>.sh`. Before each pull request the rebase list of design D15 is read against `origin/main`: `front_door.rs`, `spec/cli/tagents-core.json`, `rust.yml`, `docs/architecture/rust-core.md`, `Cargo.toml`, `Cargo.lock`, `CHANGELOG.md`, `LEARNING.md` and the two requirements of `core-front-door`.
